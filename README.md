## The entry

`main.ts` writes a single one-line joke about office life to `/output/entry.txt` — the kind of line you send a colleague after a meeting that should have been an email. Deterministic: the same 128-character text on every run, no input, no randomness, no network, no clock.

> The meeting that could have been an email just had three babies: two follow-up meetings and a spreadsheet nobody will ever open.

## Run

```sh
node main.ts   # writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt)
```
